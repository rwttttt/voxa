About VOXA

VOXA is a gesture-to-speech project built for ICT Expo 2026. Its main feature reads hand shapes through a camera and speaks them aloud — no hardware needed, works right in this browser. A second, wearable mode reads wrist motion through an MPU6050 sensor for a hands-free, camera-free alternative, demonstrated in person.
Primary mode
Camera-based hand gestures (MediaPipe, runs in your browser)
Secondary mode
Wrist sensor — MPU6050 (accelerometer + gyroscope), demoed in person
Gestures
Fist (no), Open palm (help), Thumbs up (yes), Peace sign (special) — one hand each
Output
Your browser's built-in text-to-speech
